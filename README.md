# StudentSOS Agent 🎓

StudentSOS Agent is a beginner-friendly Python project designed to provide
simple tools that help students with studying and learning.

## Features

- Calculator
- Python Quiz
- Study Planner
- Motivational Messages
- StudentSOS Main Menu

## Technologies Used

- Python
- GitHub
- GitHub Copilot
- Visual Studio Code

## Project Structure

- main.py - Main StudentSOS menu
- calculator.py - Calculator
- quiz.py - Python quiz
- planner.py - Study planner
- motivation.py - Motivational messages
- CONTRIBUTION_LOG.md - AI contribution documentation

## How to Run

1. Open the project in Visual Studio Code.
2. Open `main.py`.
3. Click **Run Python File**.
4. Select an option from the StudentSOS menu.

## AI Usage

GitHub Copilot was used as an AI coding assistant during development.

Copilot helped generate initial code structures and suggestions. The generated
code was reviewed, tested, and modified where necessary.

Detailed AI contributions are documented in `CONTRIBUTION_LOG.md`.
